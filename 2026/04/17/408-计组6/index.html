第6章 总线

6.1 总线概述

6.1.1 总线的基本概念

总线 ( Bus ) 是连接计算机系统中多个部件的公共通信线路，用于传输数据、地址和控制信号.

核心特点 :

  • 共享性 : 多个设备共享同一条总线
  • 分时性 : 同一时刻只能有一个主设备发送数据
  • 标准化 : 统一的接口标准，便于扩展

总线的作用 :

  1. 减少连线复杂度 : 将多个设备之间的点对点连接简化为总线连接
  2. 提高系统扩展性 : 新设备可直接接入总线
  3. 降低成本 : 减少硬件连线数量

6.1.2 总线的分类

按功能分类

类型 功能 特点 示例
数据总线 ( DB ) 传输数据 双向，位数与机器字长相同 32位/64位数据总线
地址总线 ( AB ) 传输地址 单向，位数决定寻址范围 32位地址总线 → 4GB寻址
控制总线 ( CB ) 传输控制信号 双向，传输时序和控制信号 读/写信号、中断请求

按层次结构分类

类型 连接范围 传输速率 典型名称
片内总线 CPU芯片内部 最高 ALU与寄存器之间
系统总线 CPU、内存、I/O接口 高 PCI、PCIe
通信总线 计算机之间或设备之间 中/低 RS-232、USB、以太网

按时序控制分类

类型 同步方式 特点
同步总线 统一时钟控制 简单、高速，但主从设备需严格同步
异步总线 握手信号控制 灵活，主从设备可异步工作，但速度较慢

系统总线标准

标准 宽度 频率 带宽 用途

通信总线标准

标准 类型 速率 距离 用途

6.1.4 总线的性能指标

指标 定义 计算方式 影响
总线宽度 一次能传输的数据位数 通常为8/16/32/64位 直接影响数据传输量
总线频率 总线工作时钟频率 MHz/GHz 频率越高，传输越快
总线带宽 单位时间传输的数据量 宽度×频率/8 (MB/s) 衡量总线传输能力
时钟同步方式 同步或异步 - 影响可靠性和速度
总线复用 地址线和数据线共用 - 减少引脚，但降低带宽
负载能力 总线上可连接的设备数 - 超过负载需加缓冲器

带宽计算公式 : \[ \text{带宽 (MB/s)} = \frac{\text{总线宽度 (位)} \times \text{总线频率 (MHz)}}{8} \]

示例 : 32位总线，33MHz → 带宽 = 32×33/8 = 132MB/s

6.1.5 总线的结构

单总线结构

优点 : 简单、成本低、易于扩展 缺点 : 所有设备共享总线，成为瓶颈

双总线结构

优点 : 内存和I/O可并行操作 缺点 : CPU需同时管理两条总线

三总线结构

优点 : 三线并行，效率最高 缺点 : 结构复杂，成本高

6.2 总线事务和定时

6.2.1 总线事务

总线事务 ( Bus Transaction ) 是指从主设备申请总线到完成数据传输的完整过程.

总线事务类型

类型 操作 方向 典型场景
读事务 从从设备读取数据 从→主 CPU读内存
写事务 向从设备写入数据 主→从 CPU写内存
读-修改-写 读数据→修改→写回 双向 原子操作
周期窃取 DMA控制器占用总线 双向 DMA传输

6.2.2 总线定时

同步定时

原理 : 所有设备使用统一的时钟信号同步操作.

特点 :

  • 优点 : 简单、高速、易于实现
  • 缺点 : 主从设备必须严格同步，灵活性差

时序图 :

异步定时

原理 : 通过握手信号 ( Handshake ) 协调主从设备操作.

特点 :

  • 优点 : 灵活，主从设备可异步工作
  • 缺点 : 速度较慢，握手开销大

全互锁握手流程 :

  1. 主设备发送 请求信号 ( REQ )
  2. 从设备收到后发送 响应信号 ( ACK )
  3. 主设备收到ACK后撤销REQ
  4. 从设备收到REQ撤销后撤销ACK

时序图 :

半同步定时

原理 : 结合同步和异步的优点，以同步时钟为基础，辅以握手信号.

特点 :

  • 使用统一时钟
  • 允许从设备延长响应时间（通过等待信号）
  • 兼顾速度和灵活性

6.3 常见问题和易混淆知识点

1. 同步总线 vs 异步总线

  • 同步总线 : 所有设备同步于同一时钟，速度快但要求严格同步
  • 异步总线 : 通过握手信号协调，灵活但速度较慢
  • 半同步总线 : 以同步为基础，允许从设备延长响应时间

选择依据 : 高速设备用同步，低速/异构设备用异步，折中方案用半同步

2. 总线带宽计算

\[ \text{带宽 (MB/s)} = \frac{\text{总线宽度 (位)} \times \text{总线频率 (MHz)}}{8} \]

注意 : 需除以8将位转换为字节；若为DDR内存，带宽需乘以2（上下沿都传输）.

3. 三总线结构的优势

三总线结构中，内存总线、DMA总线、I/O总线可并行工作 :

  • CPU通过内存总线访问内存
  • DMA控制器通过DMA总线直接访问内存
  • CPU通过I/O总线访问慢速设备

并行操作 : DMA传输时，CPU仍可执行指令，提高系统效率.

7.1 I/O系统基本概念

7.1.1 输入/输出系统

I/O系统 是计算机系统中负责与外部设备进行数据交换的子系统.

组成部分 :

  1. I/O设备 : 外部设备（键盘、鼠标、显示器、硬盘等）
  2. I/O接口 : 连接设备与主机的桥梁
  3. I/O控制方式 : 控制数据传输的方法
  4. I/O软件 : 驱动程序、设备管理软件

I/O系统的层次结构 :

7.1.2 外部设备

按功能分类

类型 示例 特点
输入设备 键盘、鼠标、扫描仪 将外部信息输入计算机
输出设备 显示器、打印机、扬声器 将计算机信息输出
存储设备 硬盘、U盘、光盘 存储数据
通信设备 网卡、调制解调器 网络通信

按传输速率分类

类型 速率范围 示例
低速设备 < 1KB/s 键盘、鼠标
中速设备 1KB/s ~ 1MB/s 打印机、扫描仪
高速设备 > 1MB/s 硬盘、网卡

按数据传输方式分类

类型 传输方式 示例
串行设备 一位一位传输 鼠标、键盘、串口
并行设备 多位同时传输 打印机、硬盘

7.2 I/O接口

7.2.1 I/O接口的功能

I/O接口 是主机与外部设备之间的桥梁，实现信号转换和数据缓冲.

核心功能 :

  1. 数据缓冲 : 匹配主机和设备的速度差异
  2. 信号转换 : 电平转换、串行/并行转换
  3. 地址译码 : 识别设备地址
  4. 命令控制 : 接收和执行主机命令
  5. 状态反馈 : 向主机报告设备状态
  6. 中断管理 : 产生和处理中断请求

7.2.2 I/O接口的基本结构

各寄存器功能 :

  • DR : 存放待传输的数据
  • CR : 存放主机发送的命令
  • SR : 存放设备当前状态（忙/闲、就绪等）
  • AR : 存放设备内部地址（如磁盘扇区号）

7.2.3 I/O接口的类型

按数据传输方式

类型 传输方式 特点 示例
串行接口 串行传输 线少、距离远、速率低 RS-232、USB
并行接口 并行传输 线多、距离近、速率高 IDE、SCSI

按通用性

类型 特点 示例
通用接口 可连接多种设备 USB、PCI
专用接口 仅连接特定设备 显卡接口、声卡接口

按总线类型

类型 总线标准 用途
PCI接口 PCI总线 扩展卡
PCIe接口 PCIe总线 高速扩展卡
SATA接口 SATA总线 硬盘
M.2接口 PCIe/NVMe SSD

7.2.4 I/O端口及其编址

I/O端口 : I/O接口中的寄存器地址.

端口编址方式

1. 统一编址 ( 存储器映射 )

  • I/O端口与内存单元统一编址
  • 使用访存指令访问I/O端口
  • 优点 : 指令丰富，无需专用I/O指令
  • 缺点 : 占用内存空间

2. 独立编址 ( I/O映射 )

  • I/O端口与内存单元独立编址
  • 使用专用I/O指令（IN/OUT）访问
  • 优点 : 不占用内存空间，地址空间独立
  • 缺点 : 指令少，编程灵活性差

对比表 :

对比项 统一编址 独立编址
地址空间 与内存统一 独立于内存
访问指令 访存指令 专用I/O指令
地址线 相同 额外I/O地址线
优点 指令丰富 不占内存空间
缺点 占内存空间 指令少

7.3.2 程序中断方式

原理 : 设备就绪后主动向CPU发送中断请求，CPU中断当前程序执行I/O操作.

流程 :

中断响应过程 :

  1. 中断请求 : 设备→中断控制器
  2. 中断判优 : 确定优先级最高的中断
  3. 中断响应 : CPU发中断响应信号
  4. 保护现场 : 保存PC、PSW等
  5. 中断服务 : 执行中断服务程序
  6. 恢复现场 : 恢复PC、PSW等
  7. 中断返回 : 返回主程序

中断优先级 :

  • 硬件优先级 : 由中断控制器决定
  • 软件优先级 : 通过屏蔽字调整

多级中断 : 高优先级中断可打断低优先级中断的执行.

特点 :

  • 优点 : CPU效率高，设备就绪时才占用CPU
  • 缺点 : 中断开销大，频繁中断影响性能

适用场景 : 中速设备、需要实时响应的系统

7.3.3 DMA方式

原理 : DMA控制器直接控制内存与设备之间的数据传输，无需CPU干预.

DMA控制器组成 :

  • MAR : 内存地址寄存器
  • MDR : 内存数据寄存器
  • DAR : 设备地址寄存器
  • DC : 数据计数器
  • CR : 控制寄存器

DMA传输流程 :

DMA传输方式 :

方式 特点 适用场景
停止CPU访问 DMA传输时CPU暂停 简单，但CPU效率低
周期窃取 DMA窃取CPU的存储周期 兼顾CPU和DMA
交替访问 CPU和DMA交替访问内存 高效，但需特殊内存

特点 :

  • 优点 : CPU效率最高，适合大批量数据传输
  • 缺点 : 硬件复杂，需要DMA控制器

适用场景 : 高速设备、大批量数据传输（如硬盘读写）

DMA与中断的区别 :

对比项 中断方式 DMA方式
数据传输 CPU执行 DMA控制器执行
CPU干预 每次传输都需CPU 仅初始化和结束时需CPU
适用场景 小批量、中低速 大批量、高速
硬件开销 小 大

7.4 常见问题和易混淆知识点

1. 三种I/O方式对比

方式 CPU干预 效率 硬件复杂度 适用场景
程序查询 全程参与 低 低 低速设备
中断 响应和处理 中 中 中速设备
DMA 初始化和结束 高 高 高速设备

选择原则 : 根据设备速度和数据量选择合适的I/O方式.

2. 中断与DMA的区别

  • 中断 : CPU执行数据传输，适合小批量、需要CPU处理的场景
  • DMA : DMA控制器执行数据传输，适合大批量、无需CPU处理的场景

关键区别 : 数据传输的执行者不同.

3. 统一编址 vs 独立编址

  • 统一编址 : I/O端口占用内存地址空间，使用访存指令访问
  • 独立编址 : I/O端口有独立地址空间，使用专用I/O指令访问

x86架构 : 使用独立编址，有专用的IN/OUT指令.
